# Gartic Phone — projet WebSockets

Application web multijoueur en temps réel inspirée de Gartic Phone, réalisée avec **Hono + WebSockets** côté serveur et **React + TypeScript + Vite** côté client dans le cadre d'un projet en temps réel à réaliser.

---

## Lancer le projet

### Prérequis
- Node.js ≥ 20
- npm ≥ 9

### Installation & démarrage

**Serveur** (terminal 1)
```bash
cd server
npm install
npm run dev
# → http://localhost:3000
```

**Client** (terminal 2)
```bash
cd client
npm install
npm run dev
# → http://localhost:5173
```

Ouvre plusieurs onglets sur `http://localhost:5173` pour simuler plusieurs joueurs.
